# 🇸🇩 Sudan AI – الذكاء الاصطناعي السوداني

المنصة الشاملة والعالمية للذكاء الاصطناعي المصممة بأعلى معايير الجودة والأمان، لدعم جميع المهام البرمجية، الكتابية، الصوتية، وتحليل المستندات، مع لمسة وبصمة بالعامية السودانية واللغات العالمية.

---

## 🌟 الميزات الرئيسية (Key Features)

1. **🎙️ أستوديو الصوت السوداني الإعلاني (Sudan Voice AI Studio):**
   - توليد وإلقاء النصوص الإعلانية والتجارية بصوت رجل حماسي وناري بالعامية السودانية.
   - التحكم في السرعة، درجة الصوت (Pitch)، ونبرات الحماس المختلفة.

2. **💬 الدردشة الذكية الشاملة (Universal AI Chat):**
   - مدعوم بأحدث نماذج Gemini AI لمعالجة استفسارات الكود البرمجي، المحتوى، والترجمة الفورية.
   - إرفاق وتحليل المستندات المباشرة (PDF, Word, Excel, PowerPoint, الصور, والملفات النصية).
   - إمكانية تصدير وحفظ سجل المحادثات بصيغة Markdown.
   - البحث الفوري والتصفية المباشرة داخل المحادثات.

3. **📁 نظام المجلدات والمشاريع (Folders & Workspace Management):**
   - تصنيف المحادثات والملفات داخل مجلدات ملونة مخصصة (برمجة، أبحاث، تسويق، إلخ).

4. **▶️ منصة تشغيل الكود المعزولة (Code Sandbox & Live Preview):**
   - معاينة وتشغيل أكواد الـ HTML/CSS/JS الناتجة عن الذكاء الاصطناعي بشكل حي ومباشر داخل بيئة آمنة ومعزولة (Iframe Sandbox).

5. **🛠️ الخدمات والتخصصات الاستشارية (Specialized AI Assistants):**
   - **القطاع الزراعي:** استشارات الري، التسميد، والمحاصيل الموسمية بالسودان.
   - **القطاع الصحي:** إرشادات وتوعية وقائية وإسعافات أولية.
   - **القطاع الهندسي والطاقة:** حساب أحمال منظومات الطاقة الشمسية والمخططات.
   - **تحليل المستندات:** استخراج الجداول والبيانات والإحصائيات من الملفات.
   - **الترجمة، التلخيص، البرمجة، والدراسة والأعمال.**

6. **📱 جاهز للتثبيت كـ تطبيق هاتف (PWA & Mobile App Store Ready):**
   - دعوة وتوجيه مباشر للتثبيت الفوري كـ تطبيق أندرويد وآيفون على الشاشة الرئيسية (Add to Home Screen).
   - قابل للتصدير إلى المتاجر Google Play & App Store.

7. **🌗 المظهر الداكن والناصع (Dark / Light Theme Modes):**
   - دعم التبديل المباشر بلمسة واحدة وحفظ تفضيل المستخدم.

---

## 🏗️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** React 18, Vite, Tailwind CSS, Lucide Icons, Motion Animation.
- **Backend:** Node.js, Express, TypeScript, tsx.
- **Database:** SQLite (better-sqlite3) مع نظام احتياطي تلقائي مقترن بـ JSON File Storage للبيئات السحابية.
- **AI Models:** Google GenAI SDK (`gemini-3.5-flash`), Web Speech Synthesis API.

---

## 🚀 تشغيل وتطوير المشروع (Getting Started)

1. **تثبيت الملحقات:**
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير:**
   ```bash
   npm run dev
   ```
   سيعمل التطبيق على المنفذ `3000` تلقائياً (`http://localhost:3000`).

3. **بناء المشروع للإنتاج:**
   ```bash
   npm run build
   npm start
   ```
